# Changelog

All notable Data Horizon Studio changes are recorded here. The project uses semantic versioning for published milestones and patch increments for ordinary development builds.

## [0.20.0] - 2026-08-25

### Added

- Verified GitHub tag-to-release automation for Windows x64.
- Version, tag, documentation, and package consistency checks.
- Packaged Electron/WebGL2 smoke validation before artifact publication.
- SHA-256 checksum and machine-readable release manifest generation.
- Git repository hygiene plus contributor and security guidance.
- Preserved GNU GPL version 3 licensing in source and binary release packages.
- Public installation, privacy, support, security, issue, and contribution surfaces.
- Full dependency auditing and GitHub-signed build provenance for release artifacts.
- Project-portable named layer selection sets and hierarchy-aware Solo/Restore.

### Existing milestone capabilities

- Non-destructive layered visualizer and broadcast-element authoring.
- Per-parameter audio drivers, editable animation, curves, motion paths, masks, effects, and paint retouching.
- Quartic Pulse, Tempest Broadcast, OBS/live, project, preset, and Asset Vault workflows using the shared renderer.
- Scalable graphics-editor workspace with custom docks, dense-project navigation, multi-layer editing, guides, and clipboard workflows.
