# Security Policy

## Supported version

Security fixes target the latest published Data Horizon Studio release. The supported public line is `0.20.x`; development snapshots and older builds are unsupported.

## Reporting a vulnerability

Please use the repository's **Security → Report a vulnerability** flow. Repository administrators must enable GitHub private vulnerability reporting before publication. Do not include exploitable details, private project files, access tokens, personal media, or Asset Vault contents in a public issue.

Include the affected version, operating system, reproducible steps, expected behavior, observed behavior, and whether a crafted project or package is required. Maintainers will coordinate validation, remediation, credit, and disclosure through the private advisory.
