# Data Horizon Studio 0.20.5

Data Horizon Studio 0.20.5 adds the Open Broadcast Kit: a neutral, transparent reference project that teaches users how practical stream elements are assembled from ordinary editable Data Horizon layers.

## Open Broadcast Kit

- Open Event Alert with editable typography, surfaces, waveform, bloom, RMS response, and fade-in animation.
- Open Chat Panel shell for use around a separate browser-chat source, with mids-reactive activity.
- Open Lower Third with editable identity text, a bass-reactive accent rail, and slide-in animation.
- Open Audio Meter with independent bass-gain and high-frequency glow drivers.
- Reactive Canvas Frame with beat-driven thickness and high-frequency bloom.
- Five portable presets that retain dependent audio assignments and Timeline tracks when reinserted.
- Automatic playback when the starter opens so all five examples are immediately discoverable.
