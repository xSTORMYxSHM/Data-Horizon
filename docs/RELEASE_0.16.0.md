# Data Horizon Studio 0.16.0

Data Horizon Studio 0.16.0 introduces complete new-project starters for Quartic Pulse and Tempest Broadcast while retaining the portable schema-version 1 authoring model.

## Release scope

- Five validated project starting points: blank, Quartic visualizer, Tempest window border, Tempest HUD overlay, and Tempest transition.
- Starter-owned layers, effects, transparency, audio mappings, animation tracks, and Quartic palette metadata.
- Optional project naming and the standard unsaved-change guard.
- Existing reusable element presets, Node View, local reference-song analysis, interface scaling, custom workspaces, masks, paths, HUD text, and export parity.

Existing projects remain compatible and normalize to engine version 0.16.0 when opened. The project schema remains version 1.
