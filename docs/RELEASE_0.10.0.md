# Data Horizon Studio 0.10.0

Release date: 2026-08-21

## Highlights

- Photoshop/GIMP-inspired non-destructive layer workspace.
- Shared WebGL2 renderer for Studio, Live View, Quartic Pulse, Tempest Broadcast, and exports.
- Image, text, shape/frame, spectrum, waveform, and particle layers.
- Cel shading, outlines, grading, luminance/region masks, posterization, bloom, scanlines, and displacement.
- Per-parameter audio assignments with smoothing, attack, release, ranges, direction, curves, and multi-source combining.
- Canvas zoom, panning, snapping, guides, safe area, transforms, and direct rotation.
- Sky, Horizon, Terrain, and Foreground mask presets.
- Lower Third, Alert, and Transition composition templates.
- Timeline animation, deterministic keyframes, playback/scrubbing, and entrance/exit presets.
- Fully wired application menus, toolbox options, color wells, Assets/Masks dock tabs, panel toggles, help, and keyboard commands.
- Persistent custom workspaces with live dock splitters, independent floating panels, exact dimension controls, and named layout saving/loading.
- Collapsible 38-pixel Timeline transport, responsive authoring controls, a consolidated preset selector, and flexible track space.
- Direct painted masks with soft Hide/Reveal brushes, layer-local transformed painting, stroke undo, and shared Studio/live/export rendering.
