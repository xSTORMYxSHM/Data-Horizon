# Data Horizon Studio 0.17.0

Data Horizon Studio 0.17.0 connects authored broadcast elements directly to the Tempest Broadcast Asset Vault.

## Release scope

- Direct Asset Vault install/update action in the Tempest publish workflow.
- Stable unique Browser Source filenames and package identities.
- Authored `tempest-size` canvas metadata and transparent output.
- Portable project, manifest, preview, and shared runtime stored together.
- Signal Reactor telemetry bridge for live music response in Vault Browser Sources.
- Broadcast-side watched-folder refresh with debounced rescanning.
- Existing project starters, reusable presets, Node View, reference songs, custom workspaces, animation, masking, and export behavior remain available.

The project schema remains version 1. Existing projects normalize to engine version 0.17.0 when opened.
