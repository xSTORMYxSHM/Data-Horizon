# Support

## Questions and feature ideas

Use GitHub Discussions when enabled. Use the feature-request template for a concrete authoring workflow that should change.

## Bugs

Use the bug-report template with the Data Horizon version, Windows version, minimal reproduction steps, expected result, actual result, and non-sensitive diagnostics. Confirm the issue still occurs in the latest published release.

Do not upload private projects, reference songs, broadcast packages, Asset Vault content, stream credentials, or personal information. Build a minimal replacement project where possible.

## Security

Vulnerabilities must follow [SECURITY.md](SECURITY.md) and should not be reported in a public issue.
